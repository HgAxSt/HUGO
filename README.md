# Hugo Strassa — portfólio

Site estático em HTML, CSS e JavaScript. Visual botânico, vintage e praiano, com as três fotos fornecidas.

## Abrir e editar

Abra esta pasta no VS Code. O arquivo `index.html` pode ser aberto diretamente no navegador, sem instalar dependências. Para uma prévia com atualização automática, use a extensão Live Server se já estiver instalada.

- `index.html`: textos, seções, projetos e contatos.
- `style.css`: cores (variáveis em `:root`), tipografia e layouts responsivos.
- `script.js`: menu acessível, cabeçalho e animações ao entrar na tela.
- `assets/`: fotos originais e elementos gráficos.

Os projetos abrem e fecham ao clicar no título. Os links de áudio e redes sociais usam os endereços do site original. O WhatsApp abre uma conversa; o e-mail abre o aplicativo de e-mail.

As fontes DM Sans e DM Serif Display carregam do Google Fonts; sem internet, o site utiliza Arial e Georgia. As fotos são locais. Animações respeitam a preferência por movimento reduzido.

## Publicação na Vercel

O conteúdo do site fica na raiz do repositório `HgAxSt/HUGO`, integrado à Vercel. O site existente é https://hugo-eight-mu.vercel.app. Atualizações na branch `main` devem disparar uma nova publicação pela integração; confira o status Vercel no commit antes de considerar a publicação concluída.

As três fotos foram fornecidas pelo proprietário. A fotografia de palco mantém sua marca de autoria.
